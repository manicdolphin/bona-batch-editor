Bona Batch Music Editor

LABORATORY V0.5.4  A safer album workshop: project recovery, duration scanning and artwork. Your music files stay on your device, and originals are never modified.

0. Project rescue 🛟

Protect your work before you switch tabs. Download a small project backup of your editing decisions. It does not contain any music. If Chrome loses this page, reopen the app, restore the project and select the original audio folder again.

Project backup works even when browser autosave does not. Audio files are never included in backups.
Browser autosave is best-effort, especially with Android's local content:// tabs. A downloaded project file is the dependable backup. Re-select your MP3s before exporting restored work. Artwork must also be reselected and approved.

1. Bring in the music

Choose a folder, select several audio files, or try the sample album. Files are read locally in your browser, not uploaded anywhere.

Folder selection depends on browser permissions; on Android, use “Choose audio files” if folder selection is unavailable. MP3 ID3 tags are read and can now be rewritten in exported copies. Other audio formats can be renamed, but their embedded tags are left unchanged. JPEG/PNG images in selected folders are detected as optional cover candidates and are not counted as tracks. A 01-03 filename is recognised as Disc 01, Track 03. V0.5.4 adds reviewable suggestions for track numbers mistakenly embedded in song titles. All V0.5.3 features remain. By default, likely mix/version descriptions in trailing brackets are separated on import (reversible in the workshop).

Examples: Hello (Fresh New Mix) → title Hello, version Fresh New Mix. Titles such as Sweet Dreams (Are Made of This) are left alone. You can restore an extracted title at any time.

2. Album-wide details

Enter information once, then apply it to all selected tracks. Blank boxes leave existing values alone. Album artist is separate from the artist credited on each track.

▸ Quick album helpers

Apply replaces existing MP3 comments on exported copies. Clear removes all MP3 ID3 comment fields, including legacy comments. Tick “Save edited ID3 tags” before exporting. Other formats remain rename-only. The source files never change.

Capitalisation affects new typing, not imported tags or notes. Turn it off for deliberate lower-case styling. Clearing album tags keeps track titles, artists, disc/track numbers, durations and artwork.

3. Filename protocols

Use a standard layout or save your own named pattern. Presets are stored in this browser, separate from the live catalogue.

Use {artist} {title} {version} {album} {year} {track} {disc} {albumartist}. The extension stays original; missing optional fields disappear.

4. Track workshop

Review the proposed names, then expand a track to edit its details.

▸ More mix tools

Unbracketed mixes are suggestions only. Accept or dismiss each one in the track card. Some named remixes may need manual adjustment.

▸ Numbered-title checks

Checks selected tracks for numbering accidentally included in their Title tag. Suggestions appear below each affected track: nothing is removed unless you approve it. Numbers that belong to the song, such as 99 Red Balloons, 17 Days and 101, are left alone by default.

Likely bracketed versions can be separated automatically. Other titles stay intact until you choose to change them. Original files are never modified.

5. Duration detective ⏱️

Measure how long each selected audio track lasts, without playing it through. This scans the audio files, not just their ID3 tags. Manually entered durations remain untouched unless you explicitly choose otherwise.

No scan performed. Tested formats include MP3 CBR, MP3 VBR, FLAC, M4A and AAC; unrecognised files are reported instead of guessed.

Results show the reading method where possible. Some browsers cannot decode every codec, so a file may need manual timing. Durations are rounded to the nearest second in MM:SS. Originals remain untouched.

6. Album cover studio

Folder artwork is detected automatically. Choose a cover for the selected MP3 tracks, or leave their existing artwork exactly as it is. Originals are always untouched.

No image files detected. You can choose a JPEG or PNG separately.
Convert a copy to JPEG, maximum 1000 pixels on its longest edge, aiming for 350 KB or less. Uncheck to embed the original JPEG/PNG bytes. Transparent PNG areas become white when optimised.

Keep existing artwork. Nothing will be embedded or replaced unless you explicitly select a new cover.

♫Artwork preview
When you choose a cover, V0.5 replaces the front-cover image in selected MP3 copies, while preserving other supported picture types. Other audio formats remain rename-only. The image is not added as a separate track or ZIP entry. Unusual MP3 tags stop the export safely.

7. Safe output

Download renamed copies in an album-named ZIP, with optional edited MP3 ID3 tags, or export a CSV manifest. Original files are never overwritten.

Suggested from selected tracks. You can change it.

A larger collection is split into numbered ZIP parts. One tap downloads each part. No-cap mode may exhaust browser memory; the ZIP32 format still has a 4 GiB ceiling.
